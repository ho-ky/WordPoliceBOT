# メッセージ検出仕様

## 概要

ユーザーが投稿した通常メッセージを監視し、登録済みの監視ワードが含まれているか判定します。

## 検出対象

- Bot 以外のユーザーが投稿したメッセージ
- 登録済み監視ワードを含むメッセージ

## 検出方式

初期実装では部分一致で判定します。

挙動の詳細:

- 判定前に以下の正規化を行います。
	- `NFKC` 正規化
	- `casefold()` による大文字・小文字の吸収
- 監視ワードの登録時は入力値をそのまま表示用に保持し、判定時のみ正規化した文字列で比較します。

## 検出時の処理

1. メッセージ内容を確認
2. サーバーに登録された監視ワードを取得
3. 一致する単語を検出
4. 検出ログを SQLite に保存
5. 通知が有効な場合、対象メッセージに返信

## 返信メッセージ例

「{word}」が検出されました。

## 補足

- 同じメッセージ内で同じ監視ワードが複数回出現した場合は、出現回数分の検出ログを保存します。
- 検出対象が複数ある場合は、各ワードをそれぞれの出現回数で記録します。
- 通知が有効なワードだけをまとめて返信し、同じワードの返信表示は1回とします。
- ワードの出現回数は重ならない部分一致で数えます。例えば、監視ワードが `aa`、本文が `aaa` の場合は1回です。
- SQLite は初期化時に `WAL` を設定し、各接続では `foreign_keys` を有効にします。

実装上のメモ:

- 検出ログは `detections` テーブルに保存します。
- 通知が有効なワードのみを返信対象に含めます。
