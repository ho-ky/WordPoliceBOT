# 入力エラー表示仕様

## 概要

`/word ranking` 実行時に、日付入力エラーと `limit` 入力エラーが同時に存在する場合、両方をまとめて表示します。

## 対象コマンド

- `/word ranking`

## 期待する動作

- 日付形式が不正な場合、その内容をエラーとして表示します。
- `limit` が範囲外の場合、その内容をエラーとして表示します。
- 複数の入力エラーがある場合は、一覧形式でまとめて通知します。
- エラーがない場合は、通常どおりランキングを表示します。

## 表示例

```text
入力内容に問題があります:
- 日付は YYYY-MM-DD 形式で指定してください。
- limit は 100 以下で指定してください。
```

## 検証項目

- `from` / `to` の日付形式
- `limit` の範囲

## 補足

- 1 つの不備だけでなく、複数の不備を同時に確認できるようにします。
- エラーがある場合は DB 集計を実行せず、ユーザーに入力内容を返します。
- 予定されている仕様として、すべての入力エラーを一覧で返す形式を採用します。
