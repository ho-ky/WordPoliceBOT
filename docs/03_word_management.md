# 監視ワード管理仕様

## 概要

Discord サーバーごとに監視ワードを登録・管理します。

## コマンド

- `/word add`
- `/word list`
- `/word edit`
- `/word delete`

挙動の詳細:

- 監視ワードはサーバーごとに管理します。
- コマンドはサーバー内でのみ利用します。
- 通知の有効・無効はワード単位で切り替えます。

## 監視ワードの項目

- ID
- サーバーID
- 単語
- 通知有効フラグ
- 作成者ID
- 作成日時
- 更新日時

実装上のメモ:

- 表示用の単語は入力値を基準に扱います。
- 重複登録や編集時の重複はエラーとして扱います。
- 一覧表示ではワード名を使って個別の編集・削除を行います。
- ID はユーザー操作には使用せず、DBの主キーおよび内部処理でのみ使用します。

## 通知設定

単語ごとに通知の有効・無効を設定できます。

通知が有効な場合、検出されたメッセージに対して Bot が返信します。
通知が無効な場合、検出ログのみ保存します。

補足:

- 通知を無効にしても検出履歴は保存します。
- 検出時の返信は、通知が有効なワードのみを対象にします。

## ワードの指定

- `edit` と `delete` は、登録済みのワードそのものを指定します。
- ワード検索時は `strip()` 後に NFKC + `casefold()` で比較します。
- `edit` では `word` に編集対象、`new_word` に変更後のワードを指定します。
