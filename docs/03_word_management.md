# 監視ワード管理仕様

## 概要

Discord サーバーごとに監視ワードを登録・管理します。

## コマンド

- `/word add`
- `/word list`
- `/word edit`
- `/word delete`

## 基本動作

- 監視ワードはサーバーごとに管理します。
- コマンドはサーバー内でのみ利用します。
- 通知の有効・無効はワード単位で切り替えます。
- 重複登録や重複編集は許可しません。

## 監視ワードの項目

- ID
- サーバーID
- 単語
- 通知有効フラグ
- 作成者ID
- 作成日時
- 更新日時

## 通知設定

単語ごとに通知の有効・無効を設定できます。

- 通知が有効な場合、検出されたメッセージに対して Bot が返信します。
- 通知が無効な場合、検出ログのみ保存します。
- 通知を無効にしても、検出履歴は保存されます。

## ワードの指定

- `edit` と `delete` は登録済みのワードそのものを対象にします。
- 検索時は入力値の前後空白を除去し、比較時に正規化を行います。
- ワードの更新は既存の値と重複しないように制御します。

## 削除結果

`delete` が成功した場合は、削除したワード名を含めて表示します。

```text
監視ワード `word` を削除しました。
```

指定したワードが存在しない場合は、削除せずエラーメッセージを表示します。
