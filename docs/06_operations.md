# 運用・公開仕様

## GitHub 公開方針

ソースコードはポートフォリオ用途として GitHub に公開します。

挙動の詳細:

- 公開対象はソースコードと仕様書を基本とします。
- 個人情報や実運用に関わる値はリポジトリに含めません。

## 公開しない情報

以下はリポジトリに含めません。

- Discord Bot Token
- 実運用DB
- `.env`

## README に記載する内容

- Bot の概要
- 使用技術
- 主な機能
- セットアップ方法
- 環境変数
- 起動方法
- コマンド一覧
- 注意事項

実装上のメモ:

- README は初見の利用者がセットアップから起動まで進める前提で記載します。
- 仕様と実装がずれた場合は README もあわせて更新します。

## `.gitignore` 対象

- `.env`
- `*.db`
- `__pycache__/`
- `.venv/`

補足:

- 実運用DB はコミットしません。
- 仮想環境や生成物は開発環境ごとに再作成できる前提で除外します。
