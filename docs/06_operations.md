# 運用・公開方針

## GitHub 公開方針

ソースコードと公開用の仕様書は、ポートフォリオ用途として GitHub に公開します。

## 公開対象

- Bot の概要とセットアップ手順
- コマンドの利用方法
- 仕様書の公開版
- ソースコード本体

## 公開しない情報

以下はリポジトリに含めません。

- Discord Bot Token
- 実運用データベース
- 本番環境の設定値
- `.env` などの秘密情報

## 推奨する運用ルール

- 開発中の実装メモや設計メモは非公開ディレクトリに分離する
- README と公開仕様書は利用者向けの説明に限定する
- 生成物やローカル依存物は `.gitignore` に含める

## `.gitignore` の対象例

- `.env`
- `*.db`
- `__pycache__/`
- `.venv/`
- `docs/internal/`

## 補足

- 実運用 DB はコミットしません。
- ローカル環境で生成されるファイルは、再生成可能な前提で除外します。
- 公開リポジトリでは、利用者がセットアップ可能な範囲の情報だけを公開します。
