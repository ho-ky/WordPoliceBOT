# WordPoliceBOT 全体仕様

## 目的

WordPoliceBOT は、Discord サーバー内のメッセージからユーザーが設定した任意の言葉を検出し、検出履歴を記録・集計する Bot です。

## 想定用途

ポートフォリオ用の公開リポジトリとして実装します。
不特定多数への配布やマルチテナント運用は前提にしません。

## 技術構成

- Python
- discord.py
- SQLite
- python-dotenv

## 主な機能

- 監視ワードの追加
- 監視ワードの一覧表示
- 監視ワードの編集
- 監視ワードの削除
- メッセージ内の監視ワード検出
- 検出時の返信通知
- 単語ごとの検出数集計
- 任意期間の検出数集計
- 単語ごとのユーザー別検出ランキング
