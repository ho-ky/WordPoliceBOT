# WordPoliceBOT 全体仕様

## 目的

WordPoliceBOT は、Discord サーバー内のメッセージから監視ワードを検出し、検出回数やランキングを記録・表示する Bot です。

## 想定用途

この Bot は、Discord サーバーの運用管理や、特定の言葉の使用状況を確認するためのツールとして利用することを想定しています。

## 技術構成

- Python
- discord.py
- SQLite
- python-dotenv

## 主な機能

- 監視ワードの追加
- 監視ワードの一覧表示
- 監視ワードの編集
- 監視ワードの削除
- メッセージ内の監視ワード検出
- 検出時の返信通知
- 単語ごとの検出数集計
- 任意期間の検出数集計
- 単語ごとのユーザー別検出ランキング

## 基本動作

- Discord サーバー内の通常メッセージを対象に、登録済みの監視ワードを検出します。
- 検出された情報は履歴として保存され、統計やランキング表示に利用されます。
- 通知が有効な監視ワードについては、検出時に Bot がメッセージへ返信します。
- 公開用のリポジトリとして、運用に関する秘密情報や個人情報は含めません。
