# 集計・ランキング仕様

## 概要

検出ログをもとに、単語ごとの検出回数やユーザー別ランキングを表示します。

## 集計コマンド

- `/word stats`
- `/word ranking`

## stats

指定した単語について、任意期間の検出回数を表示します。

指定可能な条件:

- `word_id`
- `from`
- `to`

挙動の詳細:

- `from` / `to` は未指定を許可します。未指定の場合は「全期間」として扱います。
- 日付は文字列で `YYYY-MM-DD` を受け取ります。パース後の扱いは以下の通りです。
	- `from` は当日 `00:00:00` を含む開始時刻とする。
- `to` は当日 `23:59:59` を含む終了時刻とする。
- 日付の解釈は Bot のローカルタイムゾーン（日本時間、JST）で行います。内部の `detected_at` は SQLite の `TEXT`（ISO 8601 形式、`YYYY-MM-DD HH:MM:SS`）で保存される想定のため、検索前に JST のタイムレンジに変換してください。
- 検出ログの `detected_at` は UTC で保存し、検索時に JST の日付範囲へ変換して扱います。
- 不正な日付形式が入力された場合は、デフォルト値にフォールバックせず、その場でエラーメッセージを返します。

実装上のメモ:

- 未指定の端点は SQL クエリから省略するか、広域な端点（例: `1970-01-01 00:00:00` / `9999-12-31 23:59:59`）を使って扱えます。
- 日付パースは `datetime.date.fromisoformat()` を使い、`datetime.combine(date, time(0,0,0))` / `time(23,59,59)` で端点を生成します。

## ranking

指定した単語について、任意期間内に誰が何回検出されたかをランキング形式で表示します。

表示項目:

- 順位
- ユーザー
- 検出回数

挙動の詳細:

- デフォルトで上位 `10` 件を表示します。オプション引数 `limit` を受け付け、表示件数を変更できます。
- サーバー負荷保護のため `limit` に対して上限（`max_limit`、推奨値 `100`）を設けてください。
- `limit` が上限を超えた場合は、丸めずにその場でエラーメッセージを返します。

実装上のメモ:

- 集計クエリの例（擬似）:
	- ランキング: `SELECT user_id, COUNT(*) as cnt FROM detections WHERE detected_at BETWEEN ? AND ? GROUP BY user_id ORDER BY cnt DESC LIMIT ?`
	- 単語別集計: `SELECT COUNT(*) FROM detections WHERE word_id = ? AND detected_at BETWEEN ? AND ?`
- 未指定期間はクエリから期間条件を省略することで全期間を対象とします。
- 日付解釈は `stats` と同様に JST を用いて端点を決定し、保存時刻は UTC 前提で扱ってください。

テスト要件:

- `from`/`to` が未指定・指定の両ケースのテストを追加すること。
- 日付境界（当日 00:00:00 / 23:59:59）を含む／含まないの挙動確認テストを追加すること。
- `limit` のデフォルト値・上限値制約を確認するテストを追加すること。
- 不正な `YYYY-MM-DD` 入力に対してエラーを返すテストを追加すること。
- `limit` が `max_limit` を超えた場合にエラーを返すテストを追加すること。
